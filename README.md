# Big Data Analytics & Machine Learning

A practical Big Data Analytics project exploring dimensionality reduction, statistical modelling, machine learning algorithms, and model evaluation using Python. The project investigates techniques such as Principal Component Analysis (PCA), linear regression, regression trees, and model-performance evaluation using metrics including RMSE and R².

The project also examines overfitting, model generalisation, feature selection, and dimensionality reduction, with a focus on comparing different predictive approaches and identifying methods that provide more accurate and reliable results.

## Key Topics

* Principal Component Analysis (PCA)
* Dimensionality Reduction
* Linear Regression
* Regression Trees / Decision Trees
* Model Training and Testing
* RMSE and R² Evaluation
* Overfitting and Generalisation
* Feature Selection
* Predictive Modelling
* Data Visualisation
* Machine Learning Model Comparison

## Project Highlights

The analysis compares linear regression and regression tree models using training and test data. The regression tree demonstrated stronger predictive performance, achieving lower prediction error and better generalisation than the linear regression model. The project also discusses how techniques such as PCA, feature selection, Random Forest, and Gradient Boosting could be used to further improve model performance.

This project demonstrates the application of Big Data Analytics and machine learning concepts to real-world predictive modelling problems, with an emphasis on understanding model behaviour, evaluating performance, and selecting appropriate analytical techniques.
